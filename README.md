# BTC/ETH Macro Trading Monitor

Read-only Agent Skill for BTC/USDT and ETH/USDT market analysis.

It combines:
- 15m / 1h / 4h price structure
- dynamic support and resistance
- breakout/retest and liquidity-sweep detection
- OI, funding, liquidations, options, ETF/stablecoin/CME flows
- Fed, UST, real yields, DXY, equities, VIX/MOVE/credit
- BOJ, JGB 2Y/10Y/30Y/40Y, US-Japan yield spreads, USD/JPY and carry risk
- gold, oil, war/geopolitical shocks and global USD liquidity

The engine is decision support only. It does not place orders.

## Output

LONG BIAS / SHORT BIAS / WAIT / STRUCTURE CHANGE, with one preferred entry zone, trigger, invalidation, TP1/TP2 and key risk.

## Philosophy

Trend-follow. Buy confirmed pullbacks in uptrends; short confirmed rebounds in downtrends. Do not chase. A wick is not a confirmed breakout. Key levels are configurable and must evolve with structure.
